# ИИ-профиль для холодной аудитории

Отдельная версия теста для пользователей из Reels. Старый тест и его данные не затрагиваются.

## Локальный запуск

```bash
npm test
npm run serve
```

Для проверки без отправки данных откройте сайт с параметром `?demo=1`.

## Подключение ответов

1. Создайте отдельный проект Google Apps Script.
2. Вставьте содержимое `google-apps-script.gs`.
3. Запустите `setupColdSurveyBackend` один раз.
4. Разверните проект как веб-приложение с доступом для всех.
5. Вставьте полученный `/exec` URL в `submissionEndpoint` файла `survey-config.js`.

Созданная таблица называется `Лиды из Reels — ИИ-профиль`.
